# 🐦 Flappy Bird Game

A simple yet fun clone of the classic **Flappy Bird** game.  
Built using **Python and Pygame**, this project recreates the addictive gameplay where players control a bird, avoid pipes, and aim for the highest score.

---

## 🚀 Features
- Classic Flappy Bird gameplay
- Smooth bird movement with gravity & jump mechanics
- Randomly generated pipes for endless fun
- Score tracking system
- Game over & restart functionality
- Pixel-style visuals for retro vibe

---

## 🎮 Controls
- **Spacebar / Up Arrow** → Make the bird flap (jump)
- Avoid hitting the pipes or the ground to keep playing!

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Library:** Pygame
