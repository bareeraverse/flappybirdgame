# Flappy Bird Clone 🎮

A simple **Flappy Bird clone** built using **Flutter**.  
This project demonstrates how to build a 2D game with smooth animations, collision detection, and user interaction using the **Flutter framework**.

---

## 🚀 Features
- Classic Flappy Bird gameplay 🐦  
- Tap to make the bird fly  
- Endless scrolling background  
- Score tracking system  
- Game over & restart functionality
